# Presentaciones

Las diapositivas de **Java 21 a fondo** se mantendrán como código y se versionarán junto con los guiones y ejemplos.

La opción elegida para la presentación web es **reveal.js**.

## Criterios

- Slides visuales y breves; el contenido completo vive en el guion.
- Código grande y legible.
- Diagramas antes que párrafos.
- Secciones recurrentes:
  - **OCP WATCH**
  - **VERSION WATCH**
  - **QUÉ OCURRE REALMENTE**
  - **EXPERIMENTO**
- Los archivos `slides.md` deben poder convertirse o integrarse en una presentación reveal.js.

La configuración común de reveal.js se añadirá en un paso posterior, una vez definida la identidad visual de la serie.
