# Video 2 — Anatomía de una clase Java

## Pregunta guía

¿Qué ve realmente el compilador cuando abre un archivo `.java`?

## Objetivos

Al terminar este episodio deberíamos poder:

- distinguir archivo fuente, unidad de compilación, tipo top-level y clase;
- reconocer campos, métodos y otros elementos del cuerpo de una clase;
- diferenciar **declaración de método** de **firma de método**;
- entender dónde pueden aparecer comentarios y por qué no se anidan;
- aplicar el orden `package -> import -> tipos top-level`;
- entender qué hace realmente un `import`;
- resolver imports explícitos, wildcards, `java.lang`, mismo package y conflictos de nombres;
- reconocer qué reglas son relevantes para OCP y cuáles son convenciones del mundo real.
