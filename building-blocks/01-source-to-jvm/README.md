# Video 1 — Del código fuente a la JVM

## Pregunta guía

¿Qué ocurre realmente desde que escribimos un archivo `.java` hasta que el programa se ejecuta?

## Objetivos

Al terminar este video deberíamos poder explicar:

- qué papel cumplen el JDK, `javac`, `java` y la JVM;
- qué es bytecode y qué contiene un archivo `.class`;
- cómo funciona el `main()` clásico relevante para Java 21/OCP;
- la diferencia entre compile-time y runtime;
- cómo se pasan argumentos;
- qué es **source-file mode**;
- qué problema resuelve el classpath.
